INSTITUTE PARAMETERS TEMPLATE INSTRUCTIONS
==================================================

This template contains all 27 parameters required for institute data submission.

INSTRUCTIONS:
1. Open the CSV file in Excel or any spreadsheet software
2. Fill in the 'Value' column for each parameter
3. Do NOT modify the 'Parameters' column names
4. Save the file
5. Upload via the web interface

DATA TYPE GUIDELINES:
- STRING: Text values (e.g., '1:30')
- INTEGER: Whole numbers (e.g., 100)
- DECIMAL: Decimal numbers (e.g., 2.5)
- BOOLEAN: Yes/No or True/False
- TEXT: Longer text descriptions
- LONG: Large numbers (e.g., financial amounts)

PARAMETERS LIST:
 1. Teacher-Student Ratio (STRING): e.g., 1:30
 2. Vacancy in BOYS hostel (UG) (INTEGER): Number of vacant seats
 3. Vacancy in GIRLS hostel (UG) (INTEGER): Number of vacant seats
 4. Classroom capacity (INTEGER): Total seating capacity
 5. Lift available (BOOLEAN): Yes/No or True/False
 6. Placement percentage (INTEGER): Percentage (0-100)
 7. Labs facilities (TEXT): Description of lab facilities
 8. Students going for higher studies (INTEGER): Number of students
 9. Lab equipments (INTEGER): Number of lab equipment units
10. Faculty strength (INTEGER): Total number of faculty members
11. Library resources (TEXT): Description of library resources
12. Financial capacity (LONG): Financial capacity in INR
13. Land area (sqkm) (DECIMAL): Area in square kilometers
14. Academic plan (TEXT): Description of academic plan
15. Compliance certificate (TEXT): Compliance certificate details
16. ICT facilities (TEXT): Description of ICT facilities
17. Research environment (TEXT): Description of research environment
18. Program justification (TEXT): Program justification details
19. Qualification of faculties (TEXT): Faculty qualifications description
20. Land ownership and possession (TEXT): Land ownership details
21. Building plan requirement (TEXT): Building plan details
22. Leadership qualifications (TEXT): Leadership qualifications description
23. Budget allocation (LONG): Budget allocation in INR
24. Institutional name norms (TEXT): Name norms compliance
25. Available workshops (INTEGER): Number of available workshops
26. Safety certificates (TEXT): Safety certificates details
